# HND Student Information Form & Validation

A simple web form built with **HTML**, **CSS**, and **JavaScript** to collect HND student interview information and validate required fields on the client side before submission.

## Mentorship & Context

This project was created as part of a mentoring session where **Anchimbom Denzel Kimbi** taught **Yuh Britney**, an **HND Level 2** student, how to build and validate a web form using foundational **HTML**, **CSS**, and **JavaScript**.

## Project Structure

* `index.html` — Markup for the **HND Student Information** form (Name, Surname, Birth date, Place of birth, E-mail, Phone Number, and submit button).
* `style.css` — Styling for layout, typography, input borders, and button states.
* `script.js` — Client-side validation checks ensuring Name, Surname, and E-mail (including `@`) are provided on form submission.

## Validation Rules

* **Name:** Required (cannot be blank).
* **Surname:** Required (cannot be blank).
* **E-mail:** Required and must contain `@`.
* **Other fields (Birth date, Place of birth, Phone Number):** Optional.

## How to Run

1. Download or clone the repository files (`index.html`, `style.css`, and `script.js`) into the same folder.
2. Open `index.html` in any web browser.
